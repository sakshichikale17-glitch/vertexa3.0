    Python Basics

    Lesson progress 0/4 mastered

    Learning objectives

    • Understand what variables are and why they help us store information.
    • Learn the main Python data types used in beginner coding.
    • Use print() to display results clearly.
    • Practice basic arithmetic and see how Python evaluates expressions.

    Variables

    A variable is like a labeled box where we store a value. We can then use that value later in our program.

    Real-life analogy: Think of a variable as a notebook label such as “apple_count = 5”. The label helps you find the value quickly.

    age = 18
name = "Aisha"
print(age)
print(name)

    Expected output:

    18
Aisha

    Data types

    Python stores different kinds of information in different data types. Common beginner types are integers, floats, strings, and booleans.

    • int: whole numbers like 5, -2, 12
    • float: decimal numbers like 3.5, 10.0
    • str: text like "hello"
    • bool: True or False

    Real-life analogy: A data type tells us what kind of thing is inside a box. A box might hold a number, a word, or a true/false answer.

    score = 10
pi = 3.14
message = "Ready"
passed = True

print(score)
print(pi)
print(message)
print(passed)

    Expected output:

    10
3.14
Ready
True

    Using print()

    print() shows information on the screen so we can check our program’s result.

    Real-life analogy: It is like saying “show me what is inside the box” so you can check your answer.

    print("Hello, Learner!")
print(3 + 4)

    Expected output:

    Hello, Learner!
7

    Basic arithmetic

    Python can do arithmetic just like a calculator. It follows the normal order of operations.

    total = 10 + 5
leftover = 20 - 7
product = 4 * 3
division = 12 / 3

print(total)
print(leftover)
print(product)
print(division)

    Expected output:

    15
13
12
4.0

    Variables and data types: a closer look

    A variable is a name we give to a value so we can use it later. Python automatically decides the data type based on the value stored.

    Real-life analogy: A variable is like a label on a box in a warehouse. The label tells us what is inside, and the box can hold a number, a word, or a yes/no answer.

    • int stores whole numbers such as 7, 12, or -3.
    • float stores decimals such as 3.5 or 10.0.
    • str stores text such as "hello" or "student".
    • bool stores either True or False.
    student_count = 25
average_score = 87.5
student_name = "Aisha"
passed = True

print(student_count)
print(average_score)
print(student_name)
print(passed)

    Expected output:

    25
87.5
Aisha
True

    Execution trace

    Python reads code from top to bottom, updating each variable as it goes. Here is the same idea step by step.

    hours = 3
rate = 15
pay = hours * rate
print(pay)
    Line 1hours = 3Create a variable named hours with the value 3.
    Line 2rate = 15Create a variable named rate with the value 15.
    Line 3pay = hours * ratePython calculates 3 × 15 and stores the result in pay, which becomes 45.
    Line 4print(pay)The program shows 45 on the screen.

    Expected output:

    45

    Worked example

    Suppose a student is buying notebooks. The program stores the number of notebooks, the price per notebook, and the total cost.

    notebooks = 4
price_per_book = 6
total_cost = notebooks * price_per_book
print("Total cost:")
print(total_cost)

    The first line creates a variable called notebooks and stores the integer 4. The second line stores the price 6 in price_per_book. The third line multiplies 4 × 6, which gives 24, and stores that in total_cost. The last two lines print a label and the total, so the output is:

    Expected output:

    Total cost:
24

    Step-by-step trace

    Here is a small example and how Python reads it line by line.

    first = 5
second = 3
answer = first + second
print(answer)
    1. first = 5 creates a variable with the value 5.
    2. second = 3 creates another variable with the value 3.
    3. answer = first + second adds 5 and 3 to get 8.
    4. print(answer) displays 8.

    Expected output:

    8

    Lesson summary

    Variables let us store values. Data types tell Python what kind of value we are using. The print() function helps us show information on the screen. Basic arithmetic lets us calculate values quickly and clearly.
